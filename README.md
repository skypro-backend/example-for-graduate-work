Бэкенд-часть для платформы по перепродаже вещей. Проект выполнен в рамках дипломной работы.

        Описание проекта.

Проект представляет собой REST API для платформы по перепродаже вещей. Включает:
- Регистрацию и авторизацию пользователей
- Управление объявлениями (CRUD)
- Управление комментариями к объявлениям
- Загрузку и отображение изображений (аватары пользователей, картинки объявлений)
- Ролевую модель: `USER` и `ADMIN`


        Стек технологий.

- ЯзыкJava - 17 
- Фреймворк - Spring Boot 2.7.15 
- Безопасность - Spring Security (Basic Auth) 
- База данных - PostgreSQL 18 
- Миграции - Liquibase 
- Документация API - Swagger / OpenAPI 3.0 
- Сборка - Maven 
- Фронтенд - Docker-контейнер (React) 


      Возможности.

- Регистрация и аутентификация пользователей
- Разделение ролей: `USER` (обычный пользователь) и `ADMIN` (администратор)
- Создание, просмотр, обновление, удаление объявлений
- Создание, просмотр, обновление, удаление комментариев
- Загрузка и отображение аватаров пользователей
- Загрузка и отображение картинок объявлений
- Администратор может удалять/редактировать любые объявления и комментарии

      Запуск бэкенда (Spring Boot).

- Запустить PostgreSQL.
- Открыть проект в IntelliJ IDEA.
- Настроить подключение к базе данных в файле `application.properties`:
   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:5432/buySell_db
   spring.datasource.username=postgres
   spring.datasource.password=ваш_пароль
- Запустить приложение через класс HomeworkApplication.
- Бэкенд будет доступен по адресу: http://localhost:8080


      Запуск фронтенда (Docker).

- Запустить Docker Desktop.
- Выполнить в терминале команду: docker run -p 3000:3000 --rm ghcr.io/dmitry-bizin/front-react-avito:v1.21
- Фронтенд будет доступен по адресу: http://localhost:3000


        Настройка базы данных.

- Открыть PostgreSQL 18 или выше.
- Создать базу данных: CREATE DATABASE buySell_db;
- Все таблицы создаются автоматически через Liquibase при первом запуске бэкенда.
