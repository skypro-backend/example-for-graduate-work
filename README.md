# Платформа для перепродажи вещей (Avito Clone)

Бэкенд-часть дипломного проекта для платформы по перепродаже вещей. Реализована на **Java Spring Boot** с использованием **PostgreSQL**, **Spring Security**, **MapStruct** и **Liquibase**.

---

## Стек технологий

- **Java 11**
- **Spring Boot 2.7.15**
- **Spring Data JPA** (Hibernate)
- **Spring Security** (Basic Auth)
- **PostgreSQL** (база данных)
- **Liquibase** (миграции)
- **MapStruct** (маппинг Entity ↔ DTO)
- **Lombok** (генерация кода)
- **Springdoc OpenAPI** (Swagger UI)
- **Docker** (для запуска фронтенда)

---

## Функциональность

- Регистрация и аутентификация пользователей
- Разграничение ролей: `USER` и `ADMIN`
- Создание, просмотр, редактирование и удаление объявлений
- Загрузка и отображение картинок для объявлений
- Комментарии к объявлениям (CRUD)
- Личный кабинет пользователя:
    - просмотр и обновление профиля
    - смена пароля
    - обновление аватара
- Централизованная обработка ошибок (401, 403, 404, 400)
- Документация API через Swagger UI
