# Backend для платформы объявлений (Marketplace API)

Данный проект представляет собой RESTful API для платформы объявлений (аналог онлайн-магазина). Сервис обеспечивает полный цикл публикации объявлений, комментирования товаров, управления профилем пользователя, авторизации и загрузки изображений.

---

## Технологический стек

* **Язык разработки:** Java 17 (или выше)
* **Фреймворк:** Spring Boot (Web, Security, Data JPA)
* **База данных:** PostgreSQL
* **Безопасность:** Spring Security (Basic Auth, шифрование паролей BCrypt, проверка прав на уровне методов)
* **Маппинг данных:** MapStruct
* **Генерация шаблонного кода:** Lombok
* **Документация API:** OpenAPI / Swagger (Springdoc)
* **Сборщик проектов:** Maven

---

## Основные возможности

1. **Регистрация и аутентификация:**
    - Регистрация пользователей с разделением ролей (`USER`, `ADMIN`).
    - Аутентификация по протоколу Basic Auth.
    - Безопасное хранение хэшированных паролей.
2. **Объявления (Ads):**
    - Просмотр всех объявлений (доступно неавторизованным пользователям).
    - Создание объявлений с возможностью загрузки изображения (Multipart-формат).
    - Редактирование и удаление собственных объявлений. Администратор может изменять/удалять любые объявления.
3. **Комментарии:**
    - Добавление комментариев к объявлениям.
    - Просмотр комментариев к конкретному товару.
    - Редактирование и удаление комментариев (доступно только автору комментария или администратору).
4. **Профиль пользователя:**
    - Просмотр и редактирование контактных данных (имя, фамилия, телефон).
    - Смена пароля.
    - Загрузка и обновление аватара.
5. **Медиафайлы:**
    - Локальное сохранение загружаемых изображений в директорию на сервере.
    - Предоставление статических изображений по GET-запросу.

---

## Требования к окружению

Для запуска приложения на компьютере должны быть установлены:
* **JDK 17** или выше
* **PostgreSQL**
* **Maven**

GRANT ALL PRIVILEGES ON DATABASE diplom TO admin_user;
