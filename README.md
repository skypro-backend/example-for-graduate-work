# SkyPro Ads Service

Backend-приложение для управления объявлениями пользователей.

Проект представляет собой REST API приложение для работы с объявлениями. Пользователи могут регистрироваться, авторизовываться, создавать и редактировать объявления, добавлять комментарии, управлять своим профилем, изменять пароль, а также загружать изображения объявлений и аватары.

---

В проекте используются:

- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- PostgreSQL
- Hibernate
- Liquibase
- MapStruct
- Lombok
- Swagger / OpenAPI
- Maven
- Javax Validation

# Функциональность проекта

## Пользователи

Реализовано:

- регистрация новых пользователей;
- авторизация пользователей;
- получение информации об авторизованном пользователе;
- обновление данных пользователя;
- изменение пароля;
- загрузка и обновление аватара пользователя.

---

## Объявления

Реализовано:

- получение списка всех объявлений;
- просмотр информации об объявлении;
- создание объявления;
- обновление объявления;
- удаление объявления;
- получение объявлений текущего пользователя;
- загрузка изображения объявления;
- обновление изображения объявления.

---

## Комментарии

Реализовано:

- получение списка комментариев объявления;
- добавление комментария;
- обновление комментария;
- удаление комментария.

# Авторизация и безопасность

Для защиты приложения используется:

- Spring Security;
- HTTP Basic Authentication.

В проекте реализованы роли:

- `USER`;
- `ADMIN`.

Права доступа:

- пользователь может создавать объявления и комментарии;
- пользователь может изменять и удалять только свои объявления и комментарии;
- администратор имеет расширенные права доступа.

Для загрузки пользователей используется собственная реализация:

```
CustomUserDetailsManager
```

---

# Работа с изображениями

Изображения сохраняются в файловой системе приложения.

В проекте реализовано хранение:

- изображений объявлений;
- аватаров пользователей.

В базе данных сохраняется путь к файлу изображения.

Для работы с изображениями используется отдельный сервис:

```
ImageStorageService
```

Получение изображения осуществляется через REST endpoint:

```
GET /images/{folder}/{fileName}
```

Пример:

```
GET /images/ads/example.jpg
```

---

# Настройка базы данных

Создать базу данных PostgreSQL:

```
ads
```

Настройки подключения находятся в файле:

```
src/main/resources/application.properties
```

Пример конфигурации:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/ads
spring.datasource.username=postgres
spring.datasource.password=your_password
spring.datasource.driver-class-name=org.postgresql.Driver

spring.jpa.hibernate.ddl-auto=validate

spring.liquibase.change-log=classpath:db/changelog/db.changelog-master.yaml

app.images.dir=images
```

# Обработка ошибок

В проекте реализован единый обработчик исключений:

```
GlobalExceptionHandler
```

Обрабатываются:

- отсутствие ресурса;
- отсутствие прав доступа;
- ошибки авторизации;
- некорректные запросы;
- ошибки загрузки изображений.

Используются HTTP статусы:

| Код | Описание |
|---|---|
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
