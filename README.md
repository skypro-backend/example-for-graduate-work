Платформа для перепродажи вещей

Описание проекта

Бэкенд-часть веб-приложения для размещения объявлений о продаже товаров (аналог Avito).  
Проект разработан в рамках дипломной работы курса «Java-разработчик» в SkyPro.  
Фронтенд предоставлен в готовом виде и запускается через Docker.

Функциональные возможности

- Регистрация и аутентификация пользователей.
- Разграничение ролей: `USER` и `ADMIN`.
- Объявления:
  - Просмотр всех объявлений и деталей одного объявления без авторизации.
  - Создание, редактирование и удаление своих объявлений (только для авторизованных).
  - Администратор может редактировать и удалять любые объявления.
- Комментарии:
  - Добавление, редактирование и удаление комментариев к объявлениям.
  - Редактировать/удалять можно только свои комментарии (администратор — любые).
- Работа с изображениями:
  - Загрузка и отображение картинок для объявлений.
  - Загрузка и отображение аватарок пользователей.
- Управление профилем:
  - Просмотр и редактирование личных данных.
  - Смена пароля с проверкой старого пароля.

Запуск проекта

Предварительные требования

Установленные Docker и Docker Compose, Java 11 и Maven.

Шаг 1. Запустите фронтенд

bash
docker run -p 3000:3000 --rm ghcr.io/dmitry-bizin/front-react-avito:v1.21
Фронтенд будет доступен по адресу: http://localhost:3000
Шаг 2. Запустите базу данных PostgreSQL
bash
docker run --name postgres-avito -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=shop_db -p 5433:5432 -d postgres:15
Параметры подключения:
• Порт: 5433
• Пользователь: postgres
• Пароль: postgres
• Имя БД: shop_db
Шаг 3. Соберите и запустите бэкенд
bash
mvn clean install
mvn spring-boot:run
Бэкенд запустится на порту 8080.
Шаг 4. Откройте Swagger UI
Документация API доступна по адресу:
http://localhost:8080/swagger-ui/index.html
Структура проекта
com.skypro/
├── controller/       – REST-контроллеры
├── service/          – бизнес-логика (интерфейсы и реализации)
├── repository/       – Spring Data JPA репозитории
├── entity/           – JPA-сущности
├── dto/              – объекты для передачи данных (запросы/ответы)
├── mapper/           – MapStruct-мапперы для преобразования Entity ↔ DTO
├── config/           – конфигурации (Security, Swagger, Web)
├── exception/        – кастомные исключения и глобальный обработчик ошибок
└── filter/           – фильтры (CORS)
Тестирование
Для запуска интеграционных тестов выполните:
bash
mvn test
Все тесты покрывают основные сценарии безопасности: публичный доступ, авторизация, права владельца, права администратора.
Документация API
Полная документация всех эндпоинтов доступна в Swagger UI после запуска приложения.
Также вы можете импортировать файл openapi.yaml из корня проекта в Postman или Swagger Editor.
